# hfpipes

Name reserved for an in-development Hugging Face data pipelines tool — not yet
functional. Watch this space.

Naming note: `pipes` itself cannot be registered on PyPI (former stdlib module
names are blocked, PEP 594 removal notwithstanding), so the distribution is
`hfpipes`. The import namespace and the `hf` CLI verb are deliberately free to
differ from it.
